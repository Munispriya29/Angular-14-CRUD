Angular 14 CRUD - Employee Management System

Modern and responsive Employee Management System built with Angular and Bootstrap, featuring Lazy-loaded CRUD operations, Reactive Forms validation, custom pastel themes, and dual-view (Table and Card Grid) modes.

About the Project

A sleek, responsive, and robust Employee Management Application built using Angular, Bootstrap 5, and JSON Server (REST API). It allows organizations to seamlessly onboard, update, view, and manage employee records with an intuitive and modern UI.

Features

Lazy-Loaded Architecture: Modular structure utilizing Angular Feature Modules and Lazy Routing for optimal performance.
Reactive Forms with Validation: Full client-side validation for clean and error-free data submission across Create and Edit operations.
Dual Directory Views: Switch effortlessly between a Classic Data Table and Square Card Grid View.

Theme-Coded Pages:
List and View: Crisp Sky-Blue and Slate Soft Palette.
Edit: Warm Amber and Gold Pastel Theme.
Profile Navigation: Single employee view featuring quick Previous and Next pagination shortcuts.
Delete Safeguards: In-built confirmation prompts with auto-dismissing success alert banners.
Metric Dropdown: Quick-access summary stats for total headcount and active departments.

Tech Stack
Frontend: Angular 14, TypeScript, HTML5, SCSS
Styling and UI: Bootstrap 5, Bootstrap Icons
Backend / Mock API: JSON Server (RESTful API)
Form Handling: Angular Reactive Forms
